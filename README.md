# sanak.codey — صفحة المرفق على الويب

موقع ساكن (HTML/CSS/JS بلا بناء) يعرض صفحة مرفقٍ حقيقية من نفس قاعدة بيانات
تطبيق sanak.codey: معلوماته، أطبّاءه، جدولاته، ويتيح الحجز والدخول عبر نفس دوال
الحافة (Supabase Edge Functions) التي يستعملها التطبيق — لا نسخة بيانات ثانية.

## الروابط

- `https://sanak.codey/facility/<uuid>` — صفحة مرفق (الرابط الذي يُشارَك من التطبيق).
- `https://sanak.codey/` — صفحة رئيسية بسيطة لفتح رابط مرفق يدوياً.

## كيف يعمل التوجيه على GitHub Pages

الاستضافة ساكنة بحتة — لا خادم يعيد كتابة `/facility/<uuid>` إلى ملف حقيقي.
`404.html` يلتقط أي مسار غير معروف، ويحوّله إلى `facility.html?id=<uuid>`؛
تلك الصفحة تُعيد المسار الجميل إلى شريط العنوان بـ`history.replaceState` بعد
أن تقرأ المعرّف — فيرى الزائر `/facility/<uuid>` كما هو، بقفزة واحدة غير محسوسة.

## الاتصال بـ Supabase

`js/config.js` يحمل رابط المشروع والمفتاح العام (publishable/anon). هذا
المفتاح **ليس سرّاً** — هو نفسه المضمَّن في حزمة تطبيق أندرويد، فأي محاولة
فكّ للحزمة تستخرجه أصلاً. الحدود الحقيقية (من يحجز، من يوثَّق، حدود المعدّل)
مفروضة داخل دوال الحافة نفسها لا في سرّية هذا المفتاح — وهو نفس النموذج الذي
يعمل به التطبيق المحمول.

## البنية

```
index.html          الصفحة الرئيسية
facility.html        صفحة المرفق (تُحمَّل بواسطتها الجافاسكربت أدناه)
404.html              حيلة التوجيه على GitHub Pages
css/app.css           نظام تصميم مطابق لـ lib/utils/theme.dart في التطبيق
js/config.js          رابط Supabase ومفتاحه العام
js/api.js             غلاف نداء دوال الحافة (نظير ApiService)
js/auth.js            الجلسة: دخول/تسجيل/تجديد توكن (نظير AuthService)
js/auth-ui.js          واجهة مودال الدخول والتسجيل
js/booking.js          تدفّق الحجز الكامل: تقويم → تأكيد → توثيق هاتف → إرسال
js/facility.js         منطق صفحة المرفق وربطها بكل ما سبق
```

## النشر

1. `Settings → Pages → Build and deployment → Source: Deploy from a branch`،
   واختر الفرع `main` والمجلّد `/ (root)`.
2. `CNAME` موجود بالفعل بقيمة `sanak.codey` — أضف سجلّ `CNAME`/`ALIAS` في DNS
   يشير `sanak.codey` إلى `<اسم-المستخدم>.github.io`، أو سجلّات `A` الأربعة
   الموثّقة في GitHub Pages إن كان نطاقاً جذرياً.
3. فعّل «Enforce HTTPS» بعد أن يصدر الشهادة (قد يستغرق دقائق بعد أول نشر).
